# El espectro invisible · V3

Infografía web narrativa sobre la construcción histórica del conocimiento de los rayos X, la radiactividad y las auroras.

## Desarrollo local

```bash
npm install
npm run dev
```

## Despliegue en Vercel

1. Subir el contenido de esta carpeta a un repositorio de GitHub.
2. Importar el repositorio como proyecto nuevo en Vercel.
3. Framework: Vite. Build command: `npm run build`. Output directory: `dist`.

## Nota conceptual

La relación entre tubos de descarga y auroras se presenta como analogía histórica con límites. Las auroras no son rayos X ni radiactividad y la Tierra no es literalmente un tubo de vacío.
